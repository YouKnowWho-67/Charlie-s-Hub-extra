ROBERT'S GAMES
==============

Files:
- index.html  -> homepage
- games.html  -> games page / existing game embed
- style.css   -> shared site styling
- script.js   -> small shared interactions

GitHub Pages:
1. Upload all four files to the same folder/repository.
2. Make sure index.html is in the published root.
3. Open the GitHub Pages URL.

The games page keeps the game source you provided:
https://thatoneguy-67.github.io/Games/

Important:
The game site is loaded inside an iframe. Its internal appearance is controlled by
that external site, so this site's CSS cannot directly restyle the contents inside it.

Your old notification/badge code was intentionally not copied into this version.
If you want those features, they can be added back without changing the visual design.
